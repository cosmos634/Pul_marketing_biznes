# Biznes Akademiya

O‘zbek tilidagi 30 kunlik moliya, psixologiya, marketing, savdo va biznes strategiyasi kursini o‘rganish uchun lokal web-ilova.

## Imkoniyatlar
- 5 modul va 30 kunlik dars tuzilmasi
- Darslar, bilimni tekshirish testlari va amaliy topshiriqlar
- O‘qish jarayoni, ballar, qaydlar va saqlangan darslar
- SQLite bazasi; internet va tashqi API talab qilinmaydi
- Telefon va kompyuter ekranlariga mos dizayn

## Ishga tushirish
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python seed.py
python app.py
```
Brauzerda http://127.0.0.1:5000 manzilini oching.

## Dastlabki holat
1–3-kunlar tugallangan, 4-kun joriy dars sifatida belgilanadi.
